## Решения, которые НЕ пересматривать

- **Две ленты кредлов**: Drive ← user-ADC `hnkovr@gmail.com` со скоупом `drive.file`;
  лист ← сервис-аккаунт `gsheets-reader@…` со скоупом `spreadsheets`. Причина: экран
  согласия gcloud блокирует и restricted `drive`, и **sensitive `spreadsheets`** («This app
  is blocked»); тот же логин без `spreadsheets` проходит. Не возвращать ни один из двух
  скоупов в ADC-ленту.
- `auth.scopes` обязан совпадать с реально выданным — google-auth роняет `RefreshError`
  на невыданный скоуп.
- **Quota-проект вешается на кредл** (`with_quota_project`), а не на ADC-файл: Drive API
  отказывает user-ADC без quota-проекта, а машинный ADC делят другие проекты.
- Триггер публикации только явный (`just publish-new`) — билдер мятит новую minor каждым
  билдом, авто-публикация = спам.
- Один файл на предмет без версии в имени; новая версия = `files().update` того же fileId.
- TG-отправкой владеет репо-лента; глобальный `deck-publish.yml → on_complete` остаётся
  `"open"`, иначе двойная отправка.
- dbt-дека рукописная — провенанс-штамп ей не ставить никогда.
- AGD-gen OAuth-клиент мёртв навсегда (Testing-status, 7-дневная смерть refresh-токенов) —
  не реанимировать.
