# Q&A с менеджером курса

Журнал вопросов и ответов по подготовке лекций. Источник — рабочий чат с Алиной Веденской
(менеджер образовательных проектов MLInside, [@alina_3V](https://t.me/alina_3V)) и Владом
Бояджи ([@Boyadzhi](https://t.me/Boyadzhi)), июль–август 2026. Правила, выведенные из
ответов, — [`course-rules.md`](course-rules.md); скаляры — `settings/config.yml →
course_production` (колонка «следствие» ниже ссылается на них). Трекер:
[#7 — Правила продакшена курса и Q&A с менеджером: docs, settings, блоки записи ≤25 мин, хук и агент](https://github.com/dataengy/MLInside-course/issues/7).

Формат: открытые вопросы — чекбоксы `- [ ]` в разделе **«Открытые вопросы»** (их считают
`just course-status` и SessionStart-хук `course-production-status.sh`). Закрытый вопрос
переносится в таблицу «Отвеченные» вместе с ответом, чекбокс удаляется (не отмечается).
