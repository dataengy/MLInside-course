# Память Claude Code — версионируемая копия

Рабочая память агента по этому проекту живёт **вне репозитория**, в
`~/.claude/projects/<slug>/memory/` (slug — путь основного клона, где каждый
не-буквенно-цифровой символ заменён дефисом). Это машинно-локальный каталог: на второй
станции его нет, и агент там стартует без уже выученных правил.

Здесь лежит её копия, которая ездит вместе с репозиторием.

```bash
just memory-check    # чем отличаются живая память и копия (по умолчанию)
just memory-push     # живая память → .ai/memory/   — перед коммитом
just memory-pull     # .ai/memory/ → живая память   — на новой станции
```

`MEMORY.md` — индекс: одна строка на запись, он загружается в контекст каждой сессии.
Остальные файлы — по одному факту в каждом, с `name`/`description` во фронтматтере и
разделами **Why** / **How to apply** в теле; ссылки между записями — `[[имя-файла-без-md]]`.

Две вещи, о которых стоит помнить:

- **Копия не самообновляется.** Агент пишет в живой каталог, и без `just memory-push`
  правка останется только на этой машине. Расхождение показывает `just memory-check`.
- **Синхронизация не удаляет файлы на приёмнике.** Удаление памяти — осознанное действие;
  если запись устарела, её удаляют руками в обоих местах, а не побочным эффектом `push`.

Память облачного проекта claude.ai — отдельная сущность, см.
[`docs/claude-project/memory.md`](../../docs/claude-project/memory.md): там правило
симметрии (что кладём в оба места, а что остаётся только здесь).
